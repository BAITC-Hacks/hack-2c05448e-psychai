# Готовые выгрузки для проверки

Эти файлы рассчитаны из включённых в репозиторий данных организаторов командой:

```powershell
.venv\Scripts\python run_pipeline.py --out submission
```

| Файл | Содержимое | Строк данных |
| --- | --- | ---: |
| `nodes_roles.csv` | Роль, приоритет, кластер и объяснение для каждого `gid` | 2 248 |
| `clusters.csv` | Состав, внутренний оборот и гипотеза каждой группы | 66 |
| `top_nodes.csv` | Первые узлы для проверки с причинами | 20 |

Это готовый снимок результатов для просмотра без запуска кода. Основной воспроизводимый сценарий остаётся в корневом [README](../README.md): он создаёт те же три файла в `out/`. Тесты сверяют опубликованные выгрузки с новым расчётом. Для точного поиска 18-значных `gid` используйте текстовый ввод локального просмотрщика; табличные программы могут округлять длинные числа.
