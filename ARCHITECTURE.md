# Money Graph: схема решения

```mermaid
flowchart LR
    A["Организатор: nodes, edges, transactions (.parquet)"] --> B["Проверка схемы, полноты и агрегации"]
    B --> C["Направленный взвешенный граф; все 2248 gid"]
    C --> D["Видимые потоки, степени, PageRank, связь с seed"]
    D --> E["Louvain-кластеры с фиксированным seed"]
    D --> F["Шесть объяснимых правил ролей"]
    E --> G["Детерминированный приоритет и evidence"]
    F --> G
    G --> H["Валидатор: покрытие, баллы, ссылки, CSV-схемы"]
    H --> I["nodes_roles.csv"]
    H --> J["clusters.csv"]
    H --> K["top_nodes.csv"]
    I --> L["Локальный viewer: поиск любого gid"]
    J --> L
    K --> L
    C --> L
```

Основной расчёт локальный и детерминированный; LLM не присваивает роли. Неизвестные
переводы за границей четвёртого колена и ниже 5000 KZT не реконструируются.
Результаты — гипотезы для аналитика, а не вывод о виновности.

Запуск и формальные правила: [README.md](README.md).
